# RedmineApp – Frontend

Giao diện Vue 3 cho cổng quản trị nhân sự và dự án. Backend nằm ở thư mục [`../backend`](../backend). Xem hướng dẫn chạy và danh sách chức năng ở [README chung](../README.md).

| Lệnh | Tác dụng |
| --- | --- |
| `npm run dev` | Chạy dev server (http://localhost:5173) |
| `npm run build` | Build production vào `dist/` |
| `npm run test:unit` | Unit test (Vitest) |
| `npm run test:e2e` | E2E test (Playwright) |
| `npm run lint` | oxlint + ESLint |
